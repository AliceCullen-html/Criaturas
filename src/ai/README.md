# ai — Inteligência Artificial

Tomada de decisão das criaturas, atrás de uma interface estável.

**Responsabilidades:** interface `Brain` (percepção -> intenção) e
implementações plugáveis. Permite evoluir de State Machine para Behavior Tree,
GOAP, redes neurais e algoritmos genéticos sem alterar a simulação.

**Depende de:** core, engine, creatures.
