# creatures — Criaturas

Definição de dados das criaturas (não as regras, que ficam em `simulation`).

**Responsabilidades:** componentes ECS (posição, necessidades, saúde,
felicidade, sexo, espécie, atributos físicos, idade, expectativa de vida) e o
blueprint de montagem de uma criatura.

**Depende de:** core, engine.
