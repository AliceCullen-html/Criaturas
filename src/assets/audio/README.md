# Músicas

Qualquer arquivo `.mp3`, `.ogg`, `.wav` ou `.m4a` largado aqui vira música de
fundo do jogo — não é preciso mexer em código nenhum, nem renomear o arquivo.

Com um arquivo só, ele toca em círculo. Com vários, viram uma lista em ordem de
nome que dá a volta no fim.

`M` liga e desliga o som durante o jogo.
